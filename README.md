# Bot AI – React Chat Application

A simple AI-style chatbot built using **React + TailwindCSS**, with **localStorage-based chat history**, and **new chat**.

---

## 🚀 Features

- Interactive chat with static JSON-based responses
- Default fallback message for unknown questions
- Typing indicator + smooth scrolling
- Save conversations to localStorage
- Past Conversations page with persistent history
- New Chat button to reset live chat
- Fully mobile responsive

---

## 🛠️ Setup Instructions

- npm install
- npm run dev

## 📜 Tech Used

- React
- TailwindCSS
- React Router
- LocalStorage
